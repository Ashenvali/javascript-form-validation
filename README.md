# javascript-form-validation
A fully responsive User Registration Form built using HTML, CSS, Bootstrap, and Vanilla JavaScript with custom form validation logic.

This project verifies user input fields to ensure correct data entry and prevents invalid or weak credentials using real-time validation techniques.

🚀 Live Demo

( https://cerulean-peony-8da2a4.netlify.app/ )

📖 Project Overview

Forms are a crucial part of web applications. This project demonstrates:

Client-side form validation

Event handling using onSubmit and onChange

Custom validation logic without external libraries

Clean UI design using Bootstrap

Error handling with user-friendly messages

The form ensures that users enter valid and secure information before submission.

🛠 Technologies Used

HTML5

CSS3

Bootstrap 5

JavaScript (Vanilla JS)

✅ Validation Rules Implemented

Full Name must be at least 5 characters

Email must contain @

Phone number must:

Be exactly 10 digits

Not be 1234567890

Password must:

Be at least 8 characters

Not be "password"

Not be the user's name

Confirm Password must match Password

Real-time error messages are shown on invalid input
